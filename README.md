# 📩 Contact Form with JavaScript Validation

## 📖 Project Description
This project is a simple **Contact Form** built using **HTML, CSS, and JavaScript**. It validates user inputs on the client side before allowing form submission.

---

## ✨ Features
- 👤 Name validation
- 📧 Email validation using Regular Expression (Regex)
- 💬 Message validation
- ❌ Error messages for invalid inputs
- ✅ Success message after valid submission
- 🎨 Clean and responsive design


## 🛠️ Technologies Used
- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript


## 📁 Project Structure

```text
Contact-Form/

## ✔️ Validation Rules
- 👤 Name cannot be empty.
- 📧 Email must be in a valid format.
- 💬 Message cannot be empty.
- ❌ Invalid inputs display error messages.
- ✅ Valid inputs display a success message.


## 🚀 How to Run
1. 📥 Download or clone the repository.
2. 💻 Open the project in Visual Studio Code.
3. 🌐 Run `index.html` using Live Server or any web browser.
4. 🧪 Test the form with valid and invalid inputs.


## 📸 Output
- ✅ Displays validation errors for invalid inputs.
- 🎉 Shows **"Form submitted successfully!"** after successful validation.
